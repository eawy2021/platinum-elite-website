# Platinum Elite Executive Car Service Website

This is the official website for **Platinum Elite Executive Car Service**, a private black car and executive transportation company serving Washington, DC, Maryland, and Northern Virginia.

The website was built with **HTML, CSS, and JavaScript** and deployed via **Netlify**. It integrates with **Formspree** for quote and review submissions, and with **Square** for secure online payments and invoicing.

---

## 🚖 Features

- **Responsive Design**: Mobile-first, modern UI optimized for all devices.
- **Hero Section**: Capitol skyline with a clear call-to-action.
- **About Us**: Business introduction and mission statement.
- **Services Section**: Visual cards with background images for key services:
  - Executive Protection Transport  
  - Airport Transfers  
  - Corporate Travel  
  - Weddings  
  - Proms & Special Events  
  - Hourly As-Directed  
- **Fleet Section**: Luxury Black Truck details.
- **Service Areas**: Interactive map and area highlights.
- **Client Reviews**: Testimonials + option for visitors to leave a review.
- **Contact & Quotes**: Formspree-powered request form for easy booking.
- **Secure Payments**: Integrated with [Square](https://platinum-elite-executive-car-service-ll.square.site/) for deposits and invoices.
- **Damage & Cleaning Policy**: Transparent incidentals and damage coverage.

---

## 🛠️ Tech Stack

- **Frontend**:  
  - HTML5  
  - CSS3  
  - Vanilla JavaScript  

- **Hosting**:  
  - [Netlify](https://www.netlify.com/) (free SSL, continuous deployment from GitHub)

- **Forms**:  
  - [Formspree](https://formspree.io/) (free tier supports 50 submissions/month)

- **Payments**:  
  - [Square Online Payments](https://squareup.com/)
